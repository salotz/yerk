# Explanation: yerk and PRJX

Status: **stub**

## Intent

Position `yerk` as a **host multi-project manager** that **speaks** PRJX
vocabulary without redefining the PRJX specification.

## Points (to expand)

- PRJX: project, replica, workspace (and related host/project layout ideas)
- `yerk`: catalog, materialize, path resolve, presence/change status
- Config prefixes: `YERK__…` for the tool; `PRJX__…` / `.prjx-root` for PRJX
- What `yerk` deliberately does not own yet (for example local config staging)
